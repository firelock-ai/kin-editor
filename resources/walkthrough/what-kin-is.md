## A graph-native code repository for AI agents and the people who build with them.

Git shows which lines changed. Kin shows what the change might affect.

Kin keeps code and its recorded connections together in one repository, for
AI agents and the people who build with them. It imports your Git history
without changing it or your tracked files.

In this editor, Kin's record of your code becomes an entity explorer, semantic
search over meaning rather than text, trace, go-to-definition, graph-backed
review and semantic rename.

The extension does not build a second index. Every answer comes from the local
Kin runtime, over MCP when that connection is live and the `kin` CLI when it is
not.
